# Организация проекта Gam8

- `build/` — рабочий каталог сборки и тестов. Здесь размещаются объектные файлы, конфигурация сборщика, временные загрузки, распакованные зависимости, тестовые копии ROM и BIOS, дампы и журналы.
- `dist/<платформа>/` — готовые файлы для установки или передачи. Разные архитектуры и конфигурации размещайте отдельно, если их имена файлов совпадают. В комплект поставки включайте метаданные ядра и лицензии.
- Для разового запуска создавайте собственный временный подкаталог в `build/`. Освобождайте его при успехе, ошибке и обычном прерывании. Перед удалением диагностики выведите причину ошибки. Публикуйте готовые файлы после успешной сборки.
- Для повторных ручных сборок можно сохранять явно выбранный рабочий каталог в `build/`. После завершения работы удалите его. Скрипт удаляет только созданные им временные данные. Входные архивы, установленные пользователем SDK и результаты других запусков принадлежат пользователю.
- Используйте установленные инструменты и внешние исходные коллекции напрямую. Если скачали архив специально для задачи, удалите архив, его части и временно распакованные файлы по окончании работы.
- Перед сдачей проверьте содержимое корня, `build/`, `dist/` и рабочее дерево Git. Храните обе папки с результатами вне Git.
